# arin-phone-ui

Mockup of a light-mode iPhone UI for the Arin scenario described by the user.

## 폰 훔쳐보기 · 시뮬레이터 모음

브라우저에서 바로 열리는 폰 시뮬레이터를 모아 둔 페이지입니다.

- `index.html` — 시뮬레이터를 고르는 런처 페이지
- `min-junho.html` — 드라마 〈라이어〉 민준호의 iPhone 훔쳐보기
- `yeonseok-fan.html` — 배우 유연석 팬의 스마트폰 시뮬레이터

모두 외부 라이브러리 없이 HTML/CSS/JS 한 파일로 동작합니다.
